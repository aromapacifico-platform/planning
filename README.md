# planning
Plan de trabajo trazable del caso AromaPacífico (Universidad Icesi), organizado por issues y fases.

Antes de empezar, lee [`docs/governance-and-decisions/briefing-inicial-juniors.md`](docs/governance-and-decisions/briefing-inicial-juniors.md). Ahí están el idioma de entrega, la nube principal, el patrón que se codifica en la Épica 6, la estructura de `docs/` y el registro de supuestos.

## Estructura de `docs/`

Los nombres de carpeta van en inglés (rutas/slugs); el contenido de cada documento sigue en español.

| Carpeta | Contenido |
|---|---|
| `docs/governance-and-decisions/` | Decisiones base de los Senior (idioma, nube, región, herramientas) y los borradores que adelantó el equipo junior |
| `docs/case-study/` | Enunciado del caso en Markdown |
| `docs/architecture/` | Documento y diagramas de arquitectura (Tarea 1) |
| `docs/iac/` | Plan de 100 horas (Tarea 2) y evidencia del código de infraestructura (el código vive en `aromapacifico-platform/iac`) |
| `docs/costs/` | Costo del mes normal, del mes de cosecha, del hardware de finca y de la campaña de drones (Tarea 4) |
| `docs/change/` | Plantillas y ejemplos de release notes |
| `docs/design/` | Sistema de diseño de las tres aplicaciones (Tarea 4) |
| `docs/presentation/` | Presentación, banco de preguntas y ensayo (Tarea 5) |
| `docs/cross-cutting/` | Registro de supuestos, revisión final y checklist de entrega |

El tablero de tareas vive en el [Project #2](https://github.com/orgs/aromapacifico-platform/projects/2).
